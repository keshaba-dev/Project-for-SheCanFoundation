She Can Foundation – Women Empowerment Website

A modern, responsive, and visually appealing website created for She Can Foundation, a women empowerment initiative dedicated to supporting women and girls through education, skill development, mentorship, and equal opportunities. The website highlights the foundation's mission, programs, and impact while encouraging community participation and support.

🌟 Features
Responsive and mobile-friendly design
Elegant hero section with impactful messaging
About Us section introducing the foundation
Women Empowerment section showcasing core initiatives
Focus Areas / Programs section
Smooth scrolling navigation
Animated floating navigation bar
Modern glassmorphism and gradient-based UI
Clean and accessible layout for all devices

🎯 Purpose

The purpose of this project is to spread awareness about women's empowerment and demonstrate how technology can be used to support social causes. The website serves as a digital presence for organizations working toward gender equality, education, leadership development, and economic independence for women.
